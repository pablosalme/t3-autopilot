t3-autopilot <version>: model selection MCP server for orchestrators in T3 Code, herdr and Orca.

Usage:
  t3-autopilot [serve]             Start the MCP server on stdio (what your agent CLI runs).
  t3-autopilot snippet             Print T3 Code's instructions to paste into CLAUDE.md / AGENTS.md.
  t3-autopilot snippet --host <id> Print another host's instructions (herdr, orca), or every host's (all).
  t3-autopilot init-policy         Write a commented override template to the user policy path.
  t3-autopilot --help | -h | help  Print this text.
  t3-autopilot --version | -v      Print the version.

Data directory: $T3_AUTOPILOT_HOME or ~/.t3-autopilot (policy.yaml, catalog.yaml,
subscriptions.yaml, log.jsonl, unavailable.json and the capabilities caches).
